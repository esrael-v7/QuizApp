# QuizApp

An Android Quiz App built in Java featuring Google Sign-In, password recovery (OTP), and an admin dashboard for managing questions. Optimized with smooth UI transitions and cloud sync status.

---

## Features

- Google Sign-In integration
- OTP-based password recovery
- Admin dashboard for adding/updating questions
- Local persistence and optional cloud sync
- Smooth UI transitions and polished UX

---

## Tech Stack

- Android (Java)
- Firebase (optional for auth/database)

---

## Setup & Run

1. Open the project in Android Studio.
2. If using Firebase, add your `google-services.json` to the `app/` directory and update the package name in the Firebase console.
3. Sync Gradle and build the project.
4. Run on an emulator or connected device.

---

## Notes

- Update API keys and OAuth client IDs in the project settings before releasing.
